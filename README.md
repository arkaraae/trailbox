# Trailbox

Trailbox helps a lost winter hiker get an SOS out when cell service is unreliable.

## Two-iPhone demo

The hiker records what happened, their last known location, and what help they need. Their iPhone saves the message offline. A passing snowboarder’s iPhone receives it directly when nearby, acknowledges it, and uploads it when it has service.

## Hybrid AI

**On the hiker’s phone**, AI turns their words into a short SOS covering injury, location clues, condition, and needs. The original message is kept.

**After upload**, cloud AI organizes the SOS and any later updates into a clear rescue report. It marks uncertain clues as uncertain.

## What we want to prove

One SOS moves from an offline hiker’s phone to a snowboarder’s phone, receives an acknowledgment, and is uploaded when a connection is available.

**Current status:** Build 1 is an indoor route simulator. Phone-to-phone SOS, relay, and AI are still to be built. This is a demo, not an emergency service.
